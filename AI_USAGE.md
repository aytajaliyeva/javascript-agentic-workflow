# AI Usage

## Tool used
- ChatGPT

## How AI was used
AI was used as a supplementary learning and debugging tool during the assignment.

The main usage was:
- understanding assignment requirements,
- clarifying Java concepts,
- interpreting compiler and JUnit error messages,
- discussing possible solutions for structural test failures,
- checking formatting and validation ideas.

AI was not used to automatically generate a complete final solution.

## My own work
The implementation, debugging, and final integration of the project were completed manually.

I personally:
- created and organized the project structure,
- implemented and modified the classes,
- corrected compilation and structural test problems,
- adjusted method signatures, visibility, and encapsulation,
- implemented validation and exception handling,
- created and tested workflow example files,
- executed the tests and fixed failing cases,
- reviewed and adapted all suggested code before using it.

## Verification
Every change was manually tested locally using the provided JUnit test suite, and the final version passed all tests successfully.
